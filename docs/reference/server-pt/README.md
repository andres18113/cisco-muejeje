# Server-PT historical inputs

This directory preserves the planning, decisions, assignments, and review
inputs used by the maintained
[Server-PT services change brief](../../engineering/change-briefs/server-pt-services.md).
They are historical records, not an executable instruction chain. Some files
contain superseded observations or readiness statements; current authority
remains with `AGENTS.md`, `docs/engineering/standards.md`, and the maintained
change brief.

The files were copied byte-for-byte from the corresponding sources in the
maintainer's Downloads directory on 2026-09-17. `source-manifest.json` records
the source names, archive paths, byte counts, and SHA-256 digests. The companion
overlay ZIP named by the S1 review was not present, so the individually supplied
source files were used and hash-verified without modifying or removing them.

## Contents

- `planning/rev2.2/`: the three revision 2.2 planning inputs.
- `decisions/`: the TD-12 approval and accepted S0 decision.
- `assignments/`: the historical S1 implementer assignment.
- `reviews/`: the independent review of S1 commit `0bddc9a` and its bounded
  correction authorization.
