# IOS terminal evidence

Read this reference only when the approved typed operation obtains evidence from an IOS or endpoint terminal.

Establish a freshness boundary before dispatch, correlate the current response with the requested operation, isolate only the new output window, and parse that window through the registered path. Prompt readiness and command acceptance are separate from semantic read-back. Treat paging, truncation, timeout, ambiguous echo, and parser mismatch as evidence limitations rather than successful observation.

Read `ControlledIosExecutor` in `src/packet_tracer_mcp/infrastructure/execution/ios_terminal.py` and its focused tests in `tests/test_ios_terminal.py` for current terminal APIs, queries, parsers, and failure behavior. Do not copy those volatile details into the Skill.
