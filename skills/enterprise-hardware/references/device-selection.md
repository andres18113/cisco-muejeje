# Device selection

Read this reference only for concrete candidate comparison, physical port assignment, or module-dependent demand.

1. Start from approved demand; do not recalculate growth or endpoint population here.
2. Obtain candidates and their evidence from the current capability owner for the relevant environment.
3. Eliminate candidates that demonstrably cannot meet mandatory physical requirements.
4. Keep candidates with required unknown evidence provisional and request only the missing evidence needed to decide.
5. Compare viable candidates using the planning policy supplied by the caller; a preference may break a tie but cannot make an incompatible device viable.
6. Check capacity per selected device and per failure domain, not only across the whole inventory.
7. Preserve rejection and uncertainty reasons in the result.

Physical interfaces can satisfy cable demand. Logical interfaces never do. Read current source for exact candidate states, port classes, module compatibility, and selection ordering.
