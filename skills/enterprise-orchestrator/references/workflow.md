# Orchestration workflow

## Activation

Use design skills for new enterprise intent; add IPAM and hardware after the hierarchy is stable. Add runtime only when Packet Tracer is actually operated.

## Phase mapping

- E1/E2: intent, hierarchy, segments, IPAM and capacity.
- E3: hardware and capability readiness.
- E4: concrete physical topology and layout.
- E5: typed network configuration.
- E6/E7/E8: services, voice and security.
- E9: STP, EtherChannel, HSRP and IGP resiliency.
- Acceptance, diagnosis and autofix consume evidence; they do not invent it.

## Rule

Load only the specialized Skills required by the current request. Do not load all references for a simple operation.
